DUNGEON NAVIGATION ARTWORK

## TLDR

**Yes — dungeon navigation artwork should probably be the next major art batch.** You want a modular visual library that can represent nearly any dungeon node without constantly generating one-off scenes.

## One important thing I'd add

For this particular **first-person old-school dungeon crawler**, we should establish a rigid visual standard before generating these.

Every navigation scene should have:

* Camera at identical player eye height.
* Identical field of view.
* Player centered in the corridor.
* Exits unmistakably visible.
* Same corridor width.
* Same approximate wall height.
* Same lighting direction.
* No monsters baked into the scene.
* No permanent loot baked into generic navigation scenes.
* Enough empty foreground space for combat/UI overlays.

That will prevent the AI-art drift we've already been fighting.

### Best next move

I would start with the **16-piece Core Dungeon Path Set** above and get that entire visual language approved before generating rooms. Once **Straight Corridor** is perfect, it becomes the reference image for the other 15.
