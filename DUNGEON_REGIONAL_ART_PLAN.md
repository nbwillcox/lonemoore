# Lonemoore regional art expansion — approved for production and integration

Scope: all 18 existing campaign floors across nine regions. Old City Sewers is the approved benchmark and already integrated. The owner approved this plan on 2026-09-16 and authorized production and integration of eight additional regional packs covering the remaining 16 floors, including themed keys and levers. The approved shared crate and sewer art stay in place.

Authority: current `Content/Game/Data/campaign.json`, the master build prompt, and inspected `.art/.concepts` images. Region names, floor names, lore, progression, room boundaries, collision, secrets and map/radar behavior remain authoritative. Concept labels are not new campaign regions. Reference assignments below are proposed visual associations, not claims of established one-to-one mappings.

## Production and integration after approval

1. Produce eight cohesive regional packs in an isolated art workspace: normally eight distinct 2K materials, four transparent decals and three small region-specific props each. Expected new total: 64 materials, 32 decals and 24 decorative props. Floor variation comes from geometry, material structure and wear distribution; paired floors share their regional pack.
2. Reuse the approved physical conventions: Blender metres, Unreal centimetres, 400 cm game cells, 155 cm eye height, 76-degree horizontal FOV, nominal 200 cm texture repeat / 1024 px per metre. Use actual geometry for recesses and silhouettes. Keep enemies as existing 2D sprites.
3. Use repeatable Blender scripts, editable blend sources and baked base colour / DirectX normal / roughness maps; add metallic, opacity or emission only where justified. Inspect neutral lighting and 3x3 repeats. No baked lighting in base colour, arbitrary upscaling or indiscriminate wetness. An authorized image-generation tool exists; use selectively only if illustration is needed, then validate outputs separately.
4. Prepare regional instances using reusable Unreal parents for surfaces, decals and limited emissive accents. Keep controls for physical tiling, tint, wetness, roughness and normal detail. Test imports and lighting in isolation before integration.
5. Integrate region-by-region using existing room-purpose and boundary data; decorative props never add collision or hide routes/interactions. Do not replace generation, progression, map/radar, enemies, balance, campaign lore or saves. No new cathedral/cavern layouts are included in this art pass.
6. Validate each floor in the actual game, including entrance, typical passage, feature room, doors, keys, map and 2D combat. Capture contact sheets for all 18 floors, check collision against existing logical boundaries, test regional asset loading in a fresh packaged build, and run the full regression suite. Verify save/art hashes and restore review display preferences.
7. Deliver editable sources, exports, manifests with placements/scales, isolated previews, packaged-game captures and integration notes. Retain backups. This is one coordinated production pass with internal per-region checks, not an unverified bulk replacement.

## Shared interactables — authorized now

- Lever: real cast-iron base, bolted bearing supports, axle, handle and wooden grip. Preserve the existing interaction tile and switch behavior. Material slots separate iron, grip and fasteners.
- Crate: replace the current plain loot-box visual with a planked, iron-bound wooden container at the existing footprint; model real seams, braces, lid and latch. Keep loot/chest rules and disappearance after collection unchanged. This does not add breakable-box gameplay.
- Keys: the subsequent approval authorizes six modeled world-key styles: rusted, crypt, warden, drake, infernal and Hell. Preserve camera-facing readability and the existing gentle 20 cm / 2.4 second hover of uncollected world keys. Existing inventory illustrations, pickup range, key identities and lock logic remain unchanged. Reset animation references safely on world rebuild.
